# Pokémon Type Effectiveness Quiz

An interactive web app to test and learn Pokémon type matchups — both single-type and dual-type. Built with **React** and **Vite**, this app is designed to be educational, responsive, and easy to use.

---

## Features

- Practice with the full type effectiveness chart
- Shuffle types for a randomized challenge
- Dual-type calculator mode
- Instant feedback for each input
- "Solve" buttons to reveal all correct answers
- Clean, responsive UI with color-coded types

---

## Tech Stack

- **React** (UI logic)
- **Vite** (build tool)
- **JavaScript** (core language)
- **CSS** (custom styles)

---

## Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/rithvikmattipalli/pokemon-type-quiz.git
cd pokemon-type-quiz
npm install
```
